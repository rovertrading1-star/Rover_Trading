# Rover Trading - Academy Web Application

Rover Trading is a modern, responsive React + TypeScript trading academy web application rewritten from the original static Dynamic site.

## Features

- **Interactive Landing Page**:
  - **Hero Section**: Educational candlestick price action lab with interactive HTML5 canvas simulation.
  - **About Section**: Core educational philosophy (Market understanding, Practice, Discipline).
  - **Structured Curriculum**: Three progressive learning chapters (Foundations, Advanced Analysis, Psychology & Plans).
  - **Book Edition Modal**: Preview "Read the Market like a Rover" book edition by Lethabo Loate.
  - **Course Investment / Pricing**: Standard (R150), Advanced (R250), Premium (R600), and Signals (Coming Soon).
  - **Weekly Timetable**: Scheduled group sessions, Sunday pre-class briefings, and live practice weeks.
  - **Student Reviews**: Real-time average rating calculation, verified reviews display, and interactive submission form.
  - **Enrollment Form**: Instant inquiry submission and confirmation.
  - **FAQ & Terms**: Accordion coverage of course rules, attendance, and risk disclaimers.

- **Authentication & Member Portal**:
  - **Login**: Email and password authentication with demo quick-fill options and password visibility toggle.
  - **Sign Up**: Account registration with dynamic 4-bar password strength meter and automated `RTxxxxx` account number generation.
  - **Student Dashboard**: Live account stats, subscription status (Paid/Pending), member since date, course access controls, and interactive payment verification simulation.

- **Admin Management Portal**:
  - **Member Directory**: Instant search across all accounts, full details view, and live toggles for subscription payment status (`Paid` / `Unpaid`).
  - **Enrollment Inquiries**: Prospect tracking with contact details and selected courses.
  - **Review Moderation**: Direct view of student feedback.
  - **Data Export**: JSON export of all registered members.

## Tech Stack

- **Framework**: React 19, TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Build Tool**: Vite
